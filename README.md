# مسطرة · Mastara

Interaktives Lernlabor für technisches Zeichnen, geometrische Toleranzen und Montage. Deutsch, Englisch und Arabisch.

## Lokal starten

```powershell
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

## Streamlit Community Cloud

Repository und Branch in der Cloud auswählen. Der Einstiegspunkt ist `streamlit_app.py`. Die Anwendung liefert die interaktive Website aus `dist/` mit.
